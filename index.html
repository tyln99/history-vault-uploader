History Vault Uploader

A personal desktop tool that uploads finished YouTube Shorts to the History Vault channel.

Uses YouTube API Services. This tool connects to YouTube through the YouTube Data API v3. By using it, you agree to the YouTube Terms of Service. Read how your data is handled in our Privacy Policy.

What it does

History Vault produces short documentary videos about lesser-known historical figures. The uploader runs locally on the channel owner's computer. After a video is rendered, it sends the video file, title, description and tags to YouTube using the videos.insert method.

Who it is for

This is a single-user tool. It is used only by the owner of the History Vault channel to manage uploads to that channel. It is not offered to the public and does not access any other channel.

How access works

The tool signs in with Google OAuth 2.0 and requests only the youtube.upload scope. Access tokens stay on the owner's computer. You can revoke access at any time from your Google Account permissions page.
