Privacy Policy

Effective 1 October 2026

This policy explains what data History Vault Uploader ("the tool") accesses, how it is used, and how you can delete it. The tool is a personal desktop application operated by .

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the tool accesses

  • An OAuth 2.0 access token and refresh token issued by Google, with the youtube.upload scope.
  • Basic channel information returned by YouTube when a video is uploaded, such as the channel ID and the new video's ID.
  • The video files and metadata (title, description, tags) that the channel owner chooses to upload.

How the data is used

The data is used only to upload videos to the authorized YouTube channel and to confirm that each upload succeeded. It is not used for advertising, profiling, analytics or any other purpose.

Storage and sharing

All tokens and data are stored locally on the channel owner's computer. Nothing is stored on any external server operated by the tool. The tool does not sell, share or transfer user data to any third party. Data is sent only to Google and YouTube, through the YouTube API Services, to perform uploads.

Cookies and tracking

The tool and this website do not use cookies, tracking pixels or analytics, and do not collect information from your device beyond what is listed above.

Deleting your data

  • Revoke the tool's access at any time from Google Account permissions. Once revoked, the stored tokens no longer work.
  • Delete the local token file (for example token.json in the tool's folder) to remove stored credentials from the computer.
  • To request deletion of any other stored data, email . Requests are completed within 7 days.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
